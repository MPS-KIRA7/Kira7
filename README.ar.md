# Reel Studio v1 — استوديو الريلز العلمية العربية

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) يحوّل أي **موضوع علمي** إلى ريل عمودي جاهز (**1080×1920** بمعدل **30 إطار/ثانية**) باللهجة المصرية بأسلوب سلسلة **«عارف ليه؟»**.

## المميزات الأساسية
- **خط إنتاج من 5 مراحل**: `السكربت → الصوت → التوقيت → الستوري بورد → الرندر`، مع حالة واضحة وسجل مباشر وموافقة تلقائية أو يدوية لكل مرحلة وإمكانية التعديل والإلغاء وإعادة التشغيل.
- **مؤلف سكربت مصري**: يعتمد على `references/script-style.md` مع جملة خطافة وسؤال «عارف ليه؟» وتشبيه بسيط والحفاظ على المصطلحات العلمية الإنجليزية ومعدل ~2.6 كلمة/ثانية.
- **تكاملات API قابلة للتخصيص** (مع إخفاء المفاتيح في الواجهة بآخر 4 أحرف فقط):
  - **LLM متوافق مع OpenAI** (مثل FreeLLMAPI على `http://127.0.0.1:31415/v1` أو أي رابط بديل) مع البث المباشر SSE وحذف مقاطع `<think>`.
  - **ElevenLabs TTS** (`/v1/text-to-speech/{voice}/with-timestamps`) + زر تحميل الأصوات.
  - **Deepgram** (`/v1/listen` نموذج `nova-3` عربي) لتوقيت الملفات الصوتية المرفوعة.
  - **خادم محاكاة محلي مدمج (`127.0.0.1:4399`)** للتشغيل والاختبار الكامل بدون إنترنت أو مفاتيح خارجية.
- **مزامنة الكلمات بـ LCS**: محاذاة التوقيتات على حروف كلمات السكربت الأصلية مع تعليم الكلمات الضعيفة.
- **ستوري بورد ومراجعة ذاتية**: دعم 7 أنواع مشاهد و9 قوالب بصرية (`body`, `zoom`, `flow`, `cycle`, `timeline`, `chart`, `layers`, `cards`, `meter`) مع مكتبة أيقونات محلية موحدة (`CC0` / `MIT`) ومراجعة ذاتية ثانية بالـ LLM.
- **تصدير MP4 حقيقي (H.264 + AAC)**: رندر حتمي عبر `drawFrame(t)` على لوحة `720×1280` مكبّرة `×1.5` إلى `1080×1920`، مع مؤثرات صوتية ناعمة على انتقالات المشاهد وتطبيع الصوت إلى `-14 LUFS`.
